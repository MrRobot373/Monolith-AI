# Designing with connected apps (Canva, Figma, Miro, Gamma)

Tools appear as `mcp__canva__…`, `mcp__figma__…` etc. once the person connects the app in
**Work AI → Connections**. Each person acts with their own account and its brand kits and templates.

## Canva

1. **Brief first**: format and size (Instagram post 1080×1080, story 1080×1920, A4 flyer,
   presentation 16:9), purpose, headline and body copy (write it with `marketing-content`),
   brand rules, images available.
2. **Look for brand templates** in the person's account and prefer them over generic designs;
   list a few options with names and links if more than one fits.
3. **Create the design** (generate or fill a template) with the final copy. Keep text short; one
   message per design.
4. **Review**: describe what was created (title, link, pages) and check the copy matches exactly.
5. **Export** when asked (PNG/JPG/PDF/MP4); exports are saved where the tool returns them; give the
   link or file name.

Creating, editing or exporting designs counts as a change and asks the person to approve.

## Figma

Read files and frames to extract design tokens (colors, typography, spacing), component names and
specs, or to turn a frame into implementation notes for developers (see `frontend-web-app` and
`ui-ux-design`). Reference frames by name and link.

## Miro

Summarize boards (sticky notes grouped by theme), or add structured content (e.g. a retrospective
board or user journey) after approval.

## Gamma

Generate presentations or one-pagers from an outline (write the outline with the `presentations`
skill's storyline rules first).

## When no design app is connected

Offer the alternative: write the copy and a layout description, or produce an image/PDF yourself
(charts with `charts-visualization`, documents with `pdf-documents`, slides with `presentations`),
and say that connecting Canva in Work AI → Connections would let you create the design directly.

## Done when

The design (or file) exists in the person's account or folder with the approved copy, links are
given, and every create/export step was approved.
